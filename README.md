# 3030 — эндуро, эвакуатор и лимузины в Минске

Светлый многостраничный сайт для ИП Гайшунова Вадима Сергеевича. Приоритет — прокат эндуро; у эвакуатора, лимузинов и дорожных мотоциклов свои страницы, тарифы и сценарии обращения.

Статический HTML: весь текст, цены, навигация и разметка доступны без JavaScript. Не нужны npm, база данных или платные сервисы. Фотографии и шрифты размещены в репозитории.

## Просмотр на GitHub Pages

В репозитории уже лежат готовые HTML-файлы.

1. Откройте **Settings → Pages**.
2. В **Build and deployment** выберите **Deploy from a branch**.
3. Ветка **main**, папка **/ (root)**, затем **Save**.
4. После окончания публикации адрес: `https://yaroslavkiri4ykknifhit-max.github.io/vadim/`.

GitHub Pages на момент подготовки в репозитории не был включён. Код не меняет настройки старого сайта или его DNS.

**Режим просмотра закрыт от индексации через `noindex,follow`.** Это преднамеренно: основной домен нового сайта не подтверждён, а исходный 3030.by продолжает работать. `robots.txt` разрешает обход, чтобы поисковики могли прочитать `noindex`. Для запуска основного сайта следуйте [инструкции SEO](docs/SEO-LAUNCH.md).

## Локальный просмотр и сборка

Требуется Python 3.12 или новее. Готовый сайт работает без Python на любом статическом хостинге.

```bash
python3 scripts/build.py
python3 scripts/check.py
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. Основной контент и шаблоны — `scripts/build.py`; оформление — `assets/site.css`; интерактивность — `assets/site.js`; URL и настройки индексации — `site.config.json`. После изменения шаблонов пересоберите и сохраните сгенерированные HTML-файлы. CI проверяет, что файлы соответствуют исходникам.

## Как посетитель связывается с владельцем

- Кнопки звонка открывают `+375 29 670-16-33`.
- Кнопка заказа открывает небольшое окно с выбором услуги, именем, датой и комментарием. Все поля, кроме выбранной услуги, необязательны.
- Посетитель сам выбирает Telegram `@vadim3030` или WhatsApp. Открывается личный чат с подготовленным текстом. **Сообщение отправляет сам посетитель в мессенджере.** Никакого ложного «Заявка отправлена» нет.
- Без JavaScript кнопки заказа ведут на контакты; телефоны, ссылки и весь контент продолжают работать.
- Это не серверная форма обратного звонка и не интеграция с Telegram-ботом. Секреты и токены не нужны и в публичный код не добавлены.

## SEO и реклама

Уникальные title, description, H1 и canonical; XML sitemap; robots.txt; Organization, WebSite, WebPage, Service, OfferCatalog, BreadcrumbList и SportsActivityLocation; региональные данные; перелинковка; собственная 404; Open Graph; локальные WebP с адаптивными размерами; локальные WOFF; ленивые изображения ниже первого экрана; ссылки без обязательного JS; доступное меню, диалоги и FAQ.

События для будущей аналитики: `phone_click`, `booking_open`, `messenger_click`, `messenger_open`, `price_period`. Они попадают в `dataLayer`; существующие `gtag` и `ym` вызываются, если владелец подключит счётчики. Открытие чата — намерение связаться, **не подтверждённая заявка и не продажа**. Идентификаторы и скрипты аналитики сейчас не подключены. Подробности в [SEO-LAUNCH.md](docs/SEO-LAUNCH.md).

# Проверка сайта — 2026-10-05

## Выполнено

- 11 готовых HTML-документов: 9 страниц для основного индекса, информация об обработке данных и 404.
- Проверены уникальные title/description, один H1, canonical, валидный JSON-LD, карта сайта, внутренние ссылки, якоря, локальные изображения и шрифты.
- Сборка повторяется без изменений; JavaScript проходит проверку синтаксиса.
- Проверены две конфигурации: просмотр на GitHub Pages с noindex и тестовая рабочая сборка для `https://3030.by` с индексированием. Рабочая сборка проверена локально; старый домен не изменён. После теста возвращена конфигурация просмотра.
- В Chromium проверены 10 пользовательских страниц на 320, 390, 768 и 1440 px — 40 сочетаний. Горизонтального переполнения нет. На 320 px исправлен заголовок страницы манипулятора.
- Нет ошибок JavaScript и ошибок загрузки ресурсов в браузерных проверках.
- Проверены мобильное меню, закрытие по Escape, переключение тарифов будни/выходные, сохранение выбранной услуги/модели в окне обращения, раскрытие FAQ и просмотр фотографий.
- Проверены формируемые адреса Telegram и WhatsApp и текст сообщения. Внешние переходы перехвачены тестом: реальных сообщений владельцу не отправляли.
- Проверены доступность содержимого и навигации без JavaScript: кнопка заказа ведёт на контакты, весь текст остаётся доступен.
- Фотографии после прокрутки загружаются; главный кадр имеет высокий приоритет. Изображения содержат реальные размеры, адаптивные варианты, alt и WebP.

## Что требует опубликованного основного сайта

- Настройка GitHub Pages, домена, HTTPS и HTTP-редиректов.
- Проверка ответа 404 на неизвестные URL боевого хостинга.
- Подтверждение сайта, отправка sitemap и проверка URL в Google Search Console / Яндекс Вебмастере.
- Проверка реальных идентификаторов аналитики, рекламных целей и коллтрекинга после их предоставления.
- Проверка владельцем свободных дат, расхождений цен и условий допуска.

PageSpeed/Lighthouse для опубликованного домена не запускался. Баллы производительности, индексация и позиции не заявляются как измеренные результаты.
